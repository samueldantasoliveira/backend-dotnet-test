- View -> É basicamente uma consulta estática salva 
Exemplo: Um Select de todo os usuários ativos

- Table-valued Function -> É uma função que retorna uma tabela e pode receber parâmetros 
Exemplo: uma função que retorna os alunos de um determinado plano, recebendo o Id do plano como parâmetro

- Stored Procedure -> É um conjunto de comandos SQL armazenados que podem ser executados para realizar operações no banco.
Exemplo: Uma procedure para inserir um novo usuário no banco de dados.

- Trigger -> É um código executado automaticamente em resposta a eventos como INSERT, UPDATE ou DELETE.
Exemplo: Um trigger que registra logs sempre que um usuário é criado.
